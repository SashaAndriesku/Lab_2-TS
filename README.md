# Система Управління Бібліотекою (SPA)

Веб-застосунок на **TypeScript** та **Vite** для обліку книг і користувачів із збереженням у **LocalStorage**.

## Технології
* **TypeScript** + **Vite**
* **Bootstrap** (SCSS)
* **Husky** (автоперевірка типів перед коммітом)

## Команди
* `npm install` — встановити залежності
* `npm run dev` — запустити локальний сервер
* `npm run build` — зібрати проєкт
* `npm run deploy` — задеплоїти на GitHub Pages
